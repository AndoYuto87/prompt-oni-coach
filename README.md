# prompt-oni-coach

Claude Code に発言を送るたびに、Claude の使い方の癖を Haiku が読み、関西弁のツッコミで指摘する mod です。
このまま送ると Claude との齟齬(聞き返し・的外れな作業・やり直し)が起きそうな発言は、送らずに止めて入力欄に戻し、自分で書き直してもらいます。
何日か使い、指摘される回数が減っていくのを日ごとの表で見ながら、AI への頼み方を身につけるのが目的です。

## 見る癖

| 癖 | どんな発言か |
|---|---|
| 脱線 | 前の回答の話題や、進めている作業と関係ない話を急に始める |
| 曖昧な指示 | 何を・どこを・どうしたいかが読み取れない(「いい感じにして」「直して」だけ など) |
| 前提不足 | 判断に要る材料が無い(エラーの全文・ファイル名・再現手順 など) |
| 詰め込み | 別々の作業を1回の発言にいくつも頼む |
| プランを飛ばす | 設計や大きな変更など、プランを立ててから進めた方がいい作業を、通常モードのまま頼む |

- 「OK」「2で」のような短い返事は、前の回答の問いへの答えとして通じるかで見ます。通じれば癖とは見ません
- 「プランを飛ばす」は通常モードの発言だけで見ます(下の「プランモードのとき」)

基準の文は [prompt-oni-coach/hooks/judge.ts](prompt-oni-coach/hooks/judge.ts) の `RULES` にあります。

## 何をするか

on の間、発言を送るたびに、発言(先頭 1000 字)・前の回答の末尾(400 字)・今のモードを Haiku に渡して判定させ、次のどれかにします。

| 判定 | どうなるか |
|---|---|
| 齟齬が起きそう | 送らずに止める(下の「止めたときの動き」) |
| 癖はあるが軽い | そのまま送り、ステータスラインにツッコミを一言出す |
| 癖が無い | そのまま送り、ステータスラインに褒め言葉を一言出す |

一言は、無茶ぶりされる下っ端の AI として怒ってツッコみ、苦労をぼやく形です(50 字以内)。例:「『いい感じに』て…それで外したら怒られるの俺やねんぞ!」「エラー見せんと直せて…下っ端は超能力者ちゃうねん!」「やればできるやん…最初からそうしてや」(良い発言のとき)

## 使い方

```
/prompt-oni-coach on      # ツッコミを始める(入れた直後は off)
/prompt-oni-coach off     # やめる。off の間は判定も数えることもしない
/prompt-oni-coach report  # 日ごとの回数を表で出す
/prompt-oni-coach         # 今の状態を表示する
```

on / off は次のセッションにも残ります。

| ステータスラインの表示 | 意味 |
|---|---|
| `prompt-oni-coach: on` / `prompt-oni-coach: off` | セッションの始めと、切り替えたときの状態 |
| ツッコミや褒め言葉の一言 | 直前に判定した発言への一言。次に判定するまで残る |

## 止めたときの動き

- 発言は Claude に届きません
- 送った文が入力欄に戻り、末尾に次の1行が足されます

  ```
  (この行を残して送ると、判定せずに通します)
  ```

- 止めた理由(ツッコミの一言)が、ステータスラインと、会話のグレーの1行(`Prompt dropped by a hook: …`)に出ます
- 書き直し案は出しません。足りないもの(どの癖か・何が無いか)だけを指摘するので、書き直しは自分でします

書き直したら、行の扱いで次のどちらかになります。

| 送り方 | どうなるか |
|---|---|
| 行を消して送る | もう一度判定する |
| 行を残して送る | 判定せずに通す。行は消してから Claude に渡す |

- 行は末尾でなくても、1行として残っていれば通します。行の後ろに書き足した中身も判定しません
- 判定が外れたと思ったときは、行を残したまま送れば通せます
- 入力欄に文を戻せなかったときは、文を失わないよう、止めずに送ります

## 判定しない発言

次の発言は Haiku を呼ばず、そのまま送ります。

- off の間の発言
- スラッシュコマンド(`/prompt-oni-coach` など)
- バックグラウンドの作業の完了通知(`<task-notification>` で始まる入力)と、人が打ったのではない Claude Code の入力
- AskUserQuestion のダイアログの答え(「Other」に書いた答えも判定しない)
- 強制的に通す行が残っている発言
- Haiku の返事が 5 秒以内に来ない・読めないとき

## プランモードのとき

モードは、発言の後に Claude Code から届く印(プランモードに入った・抜けた)で覚えます。発言を送る時点では今のモードが届かないためです。

- Shift+Tab などでモードを切り替えた直後の1回目の発言は、前のモードのまま判定されます。プランモードに入った直後の1回目で「プランを飛ばす」と言われることがあります
- 外れて止められたら、行を残して送れば通せます

## 日ごとの回数

on の間の発言を日ごとに数え、`/prompt-oni-coach report` で表にします。日付は手元のタイムゾーンで区切り、記録は次のセッションにも残ります。

| 列 | 数えるもの |
|---|---|
| 依頼 | Claude に届いた発言(強制的に通した発言・ダイアログの答えも入れる) |
| 止めた | 止めた発言 |
| 聞き返し | Claude が AskUserQuestion で聞き返した回数(文章で聞いた質問は数えない) |
| 中断 | Esc などでターンを止めた回数(完了通知のターンは除く) |
| 否定の言葉 | 「違う」「そうじゃない」「やり直し」などを含む発言(やり直しの目安) |
| 不具合の言葉 | 「バグ」「動かない」「エラーになる」などを含む発言(不具合の報告の目安) |

もう1つの表に、5つの癖ごとの指摘の回数(止めたときと、通して一言で指摘したとき)を出します。

上達すると、依頼の数に比べて、止めた・癖・聞き返し・中断・否定の言葉・不具合の言葉が減っていくはずです。

- 止めた発言は Claude に届いていないので、依頼にも言葉にも数えません
- 言葉は、決まった言葉を含むかだけで数えます。関係ない文でも数えることがあり、1つの発言を否定と不具合の両方に数えることもあります
- ダイアログの答えには Claude の質問文が入るので、言葉は数えません
- スラッシュコマンド・完了通知はどれにも数えません
- off の間は何も数えません

## Haiku の判定にかかる分

- Haiku を呼ぶのは、on の間、判定する発言1回につき1回です
- 渡すのは、判定基準の文・発言の先頭 1000 字・前の回答の末尾 400 字です。返事は最大 200 トークンです
- 送信は判定が終わるまで待たされます。作者の環境では 2.2〜3.9 秒でした(試しで数回測った値)。5 秒を過ぎたら判定せずに送ります

## やらないこと

- 点数は付けない。止めるか、一言で済ますかだけ
- 書き直した文や「こう書け」という案は出さない(案を写すだけだと上手にならないため)
- 止めたときにトーストは出さない(文が入力欄に戻るので気づける)
- 同じ文を送り直しただけでは通さない(通すときは行を残す)
- サブエージェントへの依頼は見ない
- 依頼から完了までの往復の数は数えない(区切りが取れないため)

## 入れ方

このリポジトリをマーケットプレイスとして登録して入れます。

```
claude plugin marketplace add AndoYuto87/prompt-oni-coach
claude plugin install prompt-oni-coach@prompt-oni-coach
```

入れた直後は off です。`/prompt-oni-coach on` で始めます。

## テスト

リポジトリの直下で:

```
claude plugin validate ./prompt-oni-coach
claude plugin test ./prompt-oni-coach
```
